# Amazon Clone 🛒

A frontend **Amazon Clone** built using **HTML and CSS**. This project recreates the visual layout of Amazon's homepage, including the navigation bar, search section, category panel, hero section, product cards, and footer.

## 📌 Project Overview

This project was created to practice and demonstrate frontend web development concepts using **HTML5 and CSS3**.

The page is designed to resemble the Amazon shopping website and includes a responsive structure with multiple sections commonly found on an e-commerce homepage.

## 🚀 Features

* Amazon-style navigation bar
* Amazon logo section
* Delivery location section
* Search bar with category dropdown
* Sign-in and account section
* Returns & Orders section
* Shopping cart section
* Navigation panel with shopping categories
* Hero/banner section
* Product category cards
* Gaming and school-supplies sections
* Footer with useful links
* "Back to Top" section
* Font Awesome icons
* Responsive viewport configuration

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and layout
* **Font Awesome** – Icons
* **Images** – Product/category images used in the homepage

## 💻 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/amazon-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No backend or additional installation is required.
